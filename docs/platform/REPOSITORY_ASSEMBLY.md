# Repository assembly record

This monorepo was assembled from four existing working directories as a clean source snapshot.

## Included

- Application source and static assets
- Package manifests and lockfiles
- Supabase migrations and functions
- Vercel, Expo and application configuration templates
- Tests and system-specific documentation
- Prepared handover Word documents

## Excluded

- `.git` directories from source projects
- `node_modules`, build output and test output
- `.env`, `.env.local` and deployment metadata
- Local databases, uploads and logs
- APKs, temporary render files and generated archives

The individual source repositories remain the historical record. This repository begins with a consolidated snapshot rather than rewritten or nested Git histories.
